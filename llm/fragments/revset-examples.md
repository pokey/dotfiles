# Git Branchless Revset Examples

This file contains examples of git-branchless revset expressions and the queries they solve.

<example>
<input>
all commits in this stack for a given ticket
</input>
<output>
stack() & message(JIRA-123)
</output>
</example>

<example>
<input>
draft commits generated by imerge
</input>
<output>
draft() & message(imerge)
</output>
</example>

<example>
<input>
all commits touching text files in the current stack
</input>
<output>
stack() & paths.changed("glob:*.txt")
</output>
</example>

<example>
<input>
all other draft commits not in the current stack
</input>
<output>
draft() - stack()
</output>
</example>

<example>
<input>
commits mentioning hello world
</input>
<output>
message("hello world")
</output>
</example>

<example>
<input>
all branches in the current stack
</input>
<output>
branches() & stack()
</output>
</example>

<example>
<input>
recently-upgraded dependencies, excluding Dependabot commits
</input>
<output>
paths.changed("Cargo.lock") & author.date("after:1 month ago") - author.email(dependabot)
</output>
</example>

<example>
<input>
commits in the current stack which aren't on a branch
</input>
<output>
stack() - ancestors(branches())
</output>
</example>

Note: In the following examples, we use the special placeholder `<my_email>`, which is replaced with the current user's email when the query is executed.
<example>
<input>
branches not created by me
</input>
<output>
stack(branches() - author.email(<my_email>))
</output>
</example>

Notes:

- the user sometimes says things like "mi" instead of "my" because the output might be from voice recognition software.
- Don't use `draft()` unless the user asks for draft commits.
- If you want to include spaces in an argument to a function, use double quotes, eg `message("hello world")`.
